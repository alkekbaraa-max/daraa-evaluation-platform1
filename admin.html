📘 دليل أنماط الشخصية الإدارية لدرعا (MBTI)

1. النمط المنفذ الرقابي والتنفيذي المحكم (ESTJ / ST)

الخصائص: واقعي، حاسم، يلتزم باللوائح والأنظمة الصارمة.

الوظائف: الرقابة الداخلية، المشتريات، والشؤون القانونية والمالية.

2. النمط المحاور والمشغل الميداني (ESTP / ST)

الخصائص: مرن، استجابة سريعة للأزمات، معالجة ميدانية للمشكلات.

الوظائف: خدمة المواطن الميدانية، الطوارئ، والتوريد التنفيذي.

3. النمط المبتكر الاستراتيجي والتقني (NT)

الخصائص: تحليلي، رؤية مستقبلية، إتقان الأنظمة البرمجية.

الوظائف: التحول الرقمي، التخطيط والإحصاء، والتطوير التنظيمي.

4. النمط الدبلوماسي والخدمي (SF)

الخصائص: تواصل فعال، امتصاص التوتر، تعاطف مع جمهور المتعاملين.

الوظائف: العلاقات العامة، النافذة الفرعية، والاستقبال.
